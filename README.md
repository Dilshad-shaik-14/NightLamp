# 🔦 Nightlamp

> **The maintenance layer for apps that have no maintainer.**

AI-built apps break silently. A dependency updates, a webhook rotates, an API key expires — and your app fails while you sleep. Nightlamp catches it first.

---

## What It Does

Nightlamp is an AI-powered diagnostic engine purpose-built for apps generated by **Cursor, Bubble, Lovable, and Bolt**.

Give it three inputs:

- A live URL
- A GitHub repo
- An error log

Gemini reads your entire stack, matches signals against a diagnostic playbook of the six most common AI-app failure modes, and returns a health report in plain English — with a fix.

```
🔴 CRITICAL  →  Active failure breaking users right now
🟡 WARNING   →  Will break within 30 days
🟢 HEALTHY   →  Module confirmed stable
```

---

## The Six Failure Modes It Catches

| Pattern | What It Means |
|---|---|
| `BROKEN_WEBHOOK` | Endpoint rejecting events — wrong auth, bad payload format |
| `EXPIRED_TOKEN` | OAuth token, API key, or JWT has expired or is expiring soon |
| `DEPRECATED_DEPENDENCY` | npm/pip package with breaking version changes or security CVEs |
| `SCHEMA_DRIFT` | Database schema changed, breaking existing queries |
| `RATE_LIMIT_FAILURE` | API hitting quota silently — returning empty responses |
| `SILENT_API_FAILURE` | Integration returning 200 but with error payload inside |

## Getting Started

### Prerequisites

- Node.js 18+
- A Gemini API key from [aistudio.google.com](https://aistudio.google.com)

---

### 1. Clone the repo

```bash
git clone https://github.com/yourusername/nightlamp.git
cd nightlamp
```

### 2. Set up the backend

```bash
cd backend
npm install
```

Create a `.env` file:

```bash
GEMINI_API_KEY=your_key_here
PORT=5000
```

Start the server:

```bash
node server.js
# or for development:
npx nodemon server.js
```

You should see:
```
Nightlamp backend running on http://localhost:5000
Gemini key loaded: true
```

Verify it's alive:
```
GET http://localhost:5000/api/health
→ { "status": "ok", "gemini": true }
```

---

### 3. Set up the frontend

```bash
cd ../frontend
npm install
npm run dev
```

Open `http://localhost:5173`

---

### 4. Run a diagnostic

Paste any of these into the input fields to test:

**URL (simulates a down server):**
```
https://httpstat.us/503
```

**Error logs (paste to simulate real failures):**
```
[ERROR] Stripe webhook signature invalid - rotating secrets
[ERROR] OpenAI API quota exceeded - returning empty response
[WARN]  axios 0.21.x deprecated - upgrade to v1.x
[ERROR] Supabase column 'user_tier' not found - schema mismatch
```

**GitHub repo (reads real package.json):**
```
https://github.com/calcom/cal.com
```

## API Reference

### `POST /api/analyze`

Runs a full diagnostic. All fields optional but at least one required.

```json
{
  "url":    "https://yourapp.com",
  "repo":   "https://github.com/org/repo",
  "logs":   "paste raw error logs here",
  "model":  "gemini-2.5-flash"
}
```

**Response:**

```json
{
  "app_name": "yourapp.com",
  "overall_status": "critical",
  "summary": "2 critical failures are breaking your payment pipeline silently.",
  "modules": [
    {
      "name": "Stripe Webhook",
      "status": "red",
      "issue_type": "BROKEN_WEBHOOK",
      "headline": "Payment webhook stopped receiving events",
      "explanation": "Your Stripe webhook is returning 401...",
      "fix_steps": ["Go to Stripe Dashboard...", "Copy the signing secret...", "Update env variable..."],
      "code_patch": "const event = stripe.webhooks.constructEvent(...)",
      "estimated_fix_time": "10 minutes",
      "severity": "critical"
    }
  ]
}
```

### `GET /api/health`

```json
{ "status": "ok", "gemini": true }
```

## Available Models

Switch models via the `model` field in the request body or the dropdown in the UI:

| Model | Speed | Best For |
|---|---|---|
| `gemini-2.5-flash` | Fast | Default — best quality |
| `gemini-2.5-flash-lite` | Faster | High traffic / fallback |
| `gemini-2.0-flash-lite` | Fastest | Rate limit fallback |

The backend automatically falls back through all three if one hits quota — the demo never crashes.

## Known Limitations

- GitHub reading only works on **public repos**
- Package.json must be at the **repo root on the `main` branch**
- Gemini 2.5 Flash free tier has a **per-minute rate limit** — wait 60 seconds between rapid test runs
- No persistent storage — reports are session-only (export JSON to save)
